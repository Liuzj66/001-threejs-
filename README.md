# 宅匠 · 家居装修 3D 交互设计室

基于 **three.js** 的家居装修 3D 交互网站：在真实比例的房间里即点即放布置家具，支持换色、旋转缩放、昼夜光照、第一人称漫游与方案存取。无需安装、无需联网、无需构建工具。

## 快速开始

直接**双击 `index.html`** 用 Chrome / Edge 打开即可（three.js 已本地化在 `js/lib/`，离线可用）。

如果浏览器策略限制了本地文件（极少数情况），可用任意静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 家具目录 | 5 大分类 · 25 件程序化建模家具，缩略图由 3D 模型实时渲染生成 |
| 放置 | 点击目录进入放置模式，鼠标跟随半透明预览，贴墙自动朝向，Shift 连续放置 |
| 编辑 | 点选家具：8 色换装 + 自定义颜色、±45° 旋转、0.8/1/1.25 缩放、复制、删除 |
| 拖拽 | 选中后直接拖动，0.25m 网格吸附（可关），自动限制在房间范围内 |
| 房间 | 开间 4–10m、进深 4–10m 实时调整；6 种墙面配色、5 种程序化地板贴图 |
| 昼夜 | 白天日照 / 夜晚暖光模式切换，落地灯与空调显示屏夜间发光 |
| 视角 | 透视 / 俯视规划 / 第一人称漫游（WASD + 鼠标环视，Esc 退出） |
| 方案 | 自动保存到浏览器；可另存命名档、导出/导入 JSON、一键导出效果图 PNG |
| 预算 | 底栏实时统计家具件数与参考总价 |

## 操作快捷键

| 按键 | 功能 |
| --- | --- |

| 鼠标右键 | 平移视角（放置模式下取消放置） |

## 技术要点

- three.js r128 经典脚本版（UMD），全部资源本地化，双击即用；
- 家具零外部模型：由 Box / Cylinder / Lathe / Icosahedron 等基础几何体按真实尺寸（米）拼装；
- 地板贴图（木纹 / 瓷砖 / 大理石）由 Canvas 2D 程序化生成并按房间尺寸平铺；
- 光照：太阳平行光（PCFSoft 阴影）+ 半球光，夜间切换暖色点光源与自发光材质；
- 数据：方案序列化为 JSON，存于 `localStorage`（自动档 `home3d.auto` / 命名档 `home3d.saved`），可导出文件分享。
