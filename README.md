# 宅匠 · 家居装修 3D 交互设计室

基于 **three.js** 的家居装修 3D 交互网站：自由画墙构建多房间户型、门窗开洞、39 件分部件调色家具、昼夜光照、第一人称漫游与方案存取。无需安装、无需联网、无需构建工具。

## 快速开始

直接**双击 `index.html`** 用 Chrome / Edge 打开即可（three.js 已本地化在 `js/lib/`，离线可用）。

如果浏览器策略限制了本地文件（极少数情况），可用任意静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 画一套自己的户型

1. 左侧切到「户型」页签 → 点「画墙」（自动切俯视视角）
2. 在地面上依次点击墙的转折点，墙会自动吸附 0.25m 网格、已有墙端点与水平/垂直方向
3. 画完按 `Esc` 或右键结束
4. 点「开门洞 / 开窗户」再点击墙段即可开洞（窗宽 1.7m、门洞 0.95m，自动避让）
5. 「删墙」点错的墙可随时拆掉重来；家具会自动收进新的房间范围

## 导入户型图纸（两种方式）

- **自己描**：「户型」页签 → 导入图片作底图 → 调透明度 → 俯视沿图描墙
- **交给我**：把户型图图片发给开发者，拆解成墙体数据后生成方案 JSON 文件，在网站顶栏「导入」即可还原成 3D 户型

## 技术要点

- three.js r128 经典脚本版（UMD），全部资源本地化，双击即用；
- 家具零外部模型：由 Box / Cylinder / Lathe / Torus / Icosahedron 等基础几何体按真实尺寸（米）拼装，颜色系统为「部件 → 材质」两级；
- 墙体为数据驱动（端点 + 开洞列表），任意改动即时重建几何：分段实体、窗框玻璃、门板踢脚线一次成形；
- 地板贴图由 Canvas 2D 程序化生成并按房间尺寸平铺；
- 画质：ACES Filmic 色调映射 + PMREM 程序化天光环境反射 + PCFSoft 软阴影；
- 数据：方案序列化为 JSON（v3 格式，兼容 v1/v2 旧档自动升级），存于 `localStorage`，可导出文件分享。
